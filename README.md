# Monofobia — Progetto Editoriale

Progetto di impaginazione e progettazione grafica editoriale per la pubblicazione "Monofobia".

## Contenuto del Repository
* **`/Links`**: Risorse grafiche e immagini utilizzate nel layout.
* **`/Document fonts`**: Famiglie di font utilizzate per la composizione tipografica.
* **`Monofobia_Chiara Giordano.indd` / `.idml`**: File sorgente di impaginazione (Adobe InDesign).
* **`Monofobia_Chiara Giordano.pdf`**: Layout finale pronto per la stampa.
* **`Monofobia_Chiara Giordano.epub`**: Edizione digitale/eBook.

## Strumenti Utilizzati
* Adobe InDesign
* Adobe Photoshop
